# Материалы по курсу СПП 2026

## Правила игры

- Посещения обязательны (почти), могут быть выборочные проверки.
- Автоматы выставляются первым 50% студентов группы, сдавшим все лабораторные работы, при условии средней оценки 8+. Оценка автоматом - средняя по лабораторным минус 1 балл. Если студен сдал лабы в первых 50%, но оценка меньше 8 - просто занял место, кто-то другой не получит автомата.
- За разные активности на лекциях, в том числе за вопросы и/или существенные исправления преподавателя ставится `+`. Каждые три `+` дают +1 балл на экзамене, вне зависимости от того, автомат или нет. Так же, потенциально будут другие активности, за которые можно будет заработать больше плюсов или другие бонусы.
- За помехи проведению лекций, например, излишнюю грмокость, студент может быть удален с лекции и/или могут быть применены штрафные санкции на экзамене.
- За пропуск каждых 4-х часов на экзамене либо доп. вопрос, либо -1 балл

## Экзамен

Список экзаменационных вопросов [находится тут](./EXAM_QUESTIONS.md).

Экзамен проводится письменно. Вся группа получает случайным образом (через генератор случайных чисел) 3 вопроса из списка. Далее есть час на написание ответов на вопросы. Через час проверка и выставление оценки. За попытки списать студент может быть удален с экзамена с выставлением отрицательной оценки в ведомость.

Для хорошей оценки, большинство ответов на вопросы должно содержать не только описание терминов, но и мотивацию зачем тот или иной подход/сущность/паттерн и т.п. появился и какую проблему он решает, а так же содержать иллюстративные примеры.
